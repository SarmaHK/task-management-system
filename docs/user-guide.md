# TaskFlow User Guide

## Getting Started

### Login
1. Go to http://localhost:5173
2. Enter your email and password
3. Click Login

### As Administrator:
- View all users in Team Members
- Register new users
- Approve/reject access requests
- Deactivate/activate users
- Change user roles
- View system logs

### As Project Manager:
- Create new projects
- Add members to projects
- Create and assign tasks
- Set task priority and deadlines
- Update task status
- Upload attachments
- Send messages in project

### As Collaborator:
- View assigned tasks
- Update task status
- Add comments on tasks
- Upload attachments
- View notifications
